# Desktop UI redesign — Phase 09 acceptance companion

## Objective and scope

User-authorized presentation redesign, not a new product phase. Preserve every
Phase 01–09 engine, transport, security, offline and acceptance behavior. No model
retraining, dependency addition or architecture/persistence changes.

## Required presentation

Persistent desktop sidebar groups repository, workspace, intelligence and system
navigation. A compact project header exposes context/status and a repository
actions disclosure. Map keeps its viewport/selection across navigation. Categories
remain available without consuming a permanent second navigation column.

Investigate leads with goal and searchable exact-file selection. Mode/depth/budget
move behind configuration disclosure. Ranked results show separate canonical
witness paths per inspected candidate: consecutive inspected candidates are not
necessarily connected. Never draw fabricated sequential edges. Fallback remains
visible in plain language with exact reasons in Details. Structural Ask, static
traces and exhaustive Impact retain their independent contracts.

Evidence offers exact-file selection and the existing hash-checked source reader.
Selected Map details and generated explanations remain available. Provider settings
remain native-storage backed; the unchanged exact-payload/approval operation is
always mounted independently of workspace visibility. Diagnostics own raw status,
coverage and watcher simulation. Settings own themes; Pilot measurements remain
local and preserve timers across navigation.

## Constraints and checks

No invented branch/network/model-availability indicators. Stored snapshot time and
watcher state do not prove all disk files are current. Distinguish generated
explanations, ranking priorities and verified structural witnesses. Accessible
labels, keyboard-operable disclosures/file selection and visible focus; fixed
desktop typography with usable layouts from 1000px window width upward.

Run Next typegen/typecheck/lint, full JS tests, Rust fmt/check/tests, static build,
offline asset checks, staged/release smoke, model/package hash checks and diff
whitespace checks. Rebuild Windows MSI/NSIS without changing pinned weights.
Manual review follows the Phase 09 guide with relocated navigation documented
in a UI review guide. Existing macOS/Linux and pilot gaps remain open.
